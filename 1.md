# 🏏 Cricket Match Results Analysis

## 📌 Problem Statement
We are given a dataset containing cricket match results with the following columns:
- `Team_1`
- `Team_2`
- `Winner`

### 🎯 Objective
Our goal is to calculate for each team:
- Total matches played
- Total matches won
- Total matches lost

⚠️ Challenge:
Each match has **two teams in a single row**, so we must ensure both teams are counted correctly.

---

## Dataset

| Team_1 | Team_2 | Winner |
|--------|--------|--------|
| India  | SL     | India  |
| SL     | Aus    | Aus    |
| SA     | Eng    | Eng    |
| Eng    | NZ     | NZ     |
| Aus    | India  | India  |

---

## Table Creation & Data Insertion

```sql
CREATE TABLE match_results (
    Team_1 VARCHAR(50),
    Team_2 VARCHAR(50),
    Winner VARCHAR(50)
);

INSERT INTO match_results (Team_1, Team_2, Winner) VALUES 
('India', 'SL', 'India'),
('SL', 'Aus', 'Aus'),
('SA', 'Eng', 'Eng'),
('Eng', 'NZ', 'NZ'),
('Aus', 'India', 'India');
```

```sql
WITH teams_win AS (
    SELECT Team_1 AS team,
           CASE WHEN Team_1 = Winner THEN 1 ELSE 0 END AS win_flag 
    FROM match_results
    
    UNION ALL
    
    SELECT Team_2 AS team,
           CASE WHEN Team_2 = Winner THEN 1 ELSE 0 END AS win_flag 
    FROM match_results
)

SELECT 
    team,
    COUNT(*) AS total_matches,
    SUM(win_flag) AS total_wins,
    (COUNT(*) - SUM(win_flag)) AS total_loss
FROM teams_win
GROUP BY team;
```

## Step-by-Step Explanation
### 1️⃣ Data Transformation (CTE: teams_win)

We split each match into two rows:

One for Team_1
One for Team_2

Each row includes a win_flag:

1 → if the team won
0 → if the team lost

## 2️⃣ UNION ALL

We use UNION ALL to combine both teams:

Ensures every team is counted per match
Avoids data loss
