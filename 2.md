## 📌 Problem Statement

We are given an orders dataset containing:
- order_id
- customer_id
- order_date
- order_amount
  
## 🎯 Objective
For each order date, we need to calculate:
- Number of new customers (customers placing their first-ever order)
- Number of repeat customers (customers who have ordered before)

## ⚠️ Challenge
- A customer can place multiple orders across different dates
- We must correctly identify their first purchase date
Then classify each order as:
- New (first visit)
- Repeat (subsequent visits)

## Solution :
```sql
WITH cte AS (
    SELECT customer_id, MIN(order_date) AS first_visit_date 
    FROM orders 
    GROUP BY customer_id
),
cte2 AS (
    SELECT 
        o.order_date,
        CASE WHEN o.order_date = c.first_visit_date THEN 1 ELSE 0 END AS first_visit_flag,
        CASE WHEN o.order_date <> c.first_visit_date THEN 1 ELSE 0 END AS repeat_visit_flag
    FROM orders o 
    JOIN cte c ON o.customer_id = c.customer_id
)
SELECT 
    order_date,
    SUM(first_visit_flag) AS new_customer_count,
    SUM(repeat_visit_flag) AS repeat_customer_count
FROM cte2
GROUP BY order_date
ORDER BY order_date;
```
