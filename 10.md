- A company has a "candidates" table with columns emp_id, experience ("junior" or "senior"), and salary.
- With a budget of $70,000, the company follows these hiring criteria:
- Hire seniors first, starting with the lowest salary, until the remaining budget can't cover the next senior.
- Use the remaining budget to hire juniors, starting with the lowest salary, until the budget is exhausted.

--Write an SQL query to determine which seniors and juniors will be hired based on these rules.

```sql
CREATE TABLE employees (
    emp_id INT PRIMARY KEY,
    experience VARCHAR(50),
    salary INT
);

```sql
INSERT INTO employees (emp_id, experience, salary) VALUES
(1, 'Junior', 10000),
(2, 'Junior', 15000),
(3, 'Junior', 40000),
(4, 'Senior', 16000),
(5, 'Senior', 20000),
(6, 'Senior', 50000);

select * from employees;

```sql
WITH cte AS (
    SELECT *, 
           SUM(salary) OVER(PARTITION BY experience ORDER BY salary) AS running_salary 
    FROM employees
),
cte2 AS (
    SELECT *
    FROM cte
    WHERE experience = 'Senior' AND running_salary <= 70000
)
-- Select Juniors using the remaining budget
SELECT *
FROM cte
WHERE experience = 'Junior' 
  AND running_salary <= (70000 - (SELECT COALESCE(SUM(salary), 0) FROM cte2))

UNION ALL

-- Select the Seniors we already identified
SELECT * FROM cte2;
