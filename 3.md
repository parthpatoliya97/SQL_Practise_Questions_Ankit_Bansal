## Dataset :
| name | address | email | floor | resources |
| :--- | :--- | :--- | :--- | :--- |
| A | Bangalore | A@gmail.com | 1 | CPU |
| A | Bangalore | A1@gmail.com | 1 | CPU |
| A | Bangalore | A2@gmail.com | 2 | DESKTOP |
| B | Bangalore | B@gmail.com | 2 | DESKTOP |
| B | Bangalore | B1@gmail.com | 2 | DESKTOP |
| B | Bangalore | B2@gmail.com | 1 | MONITOR |

------------------------

## Solution :
```sql
WITH floor_counts AS (
    SELECT 
        name,
        floor,
        resources,
        COUNT(*) OVER(PARTITION BY name, floor) as visit_count,
        COUNT(*) OVER(PARTITION BY name) as total_visits
    FROM office_resources
),
ranked_floors AS (
    SELECT 
        name,
        floor,
        total_visits,
        resources,
        -- Rank floors by visit count to find the top one
        RANK() OVER(PARTITION BY name ORDER BY visit_count DESC) as rnk
    FROM floor_counts
)
SELECT 
    name,
    total_visits,
    floor AS most_visited_floor,
    GROUP_CONCAT(DISTINCT resources SEPARATOR ', ') AS resources_used
FROM ranked_floors
WHERE rnk = 1
GROUP BY name, total_visits, floor;
```

| :--- | :---: | :---: | :--- |
